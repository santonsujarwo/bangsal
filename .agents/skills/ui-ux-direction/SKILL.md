# UI/UX Direction
1. Review brand assets, audience, content hierarchy, and references.
2. Define visual concept before coding.
3. Specify colors, typography, spacing, grid, containers, breakpoints, imagery, buttons, forms, and interaction states.
4. Choose layout patterns based on content; do not default to cards or Bento grids.
5. Preserve approved copy.
6. Include keyboard, focus, contrast, reduced-motion, and mobile behavior.
7. Deliver design system and page-level layout notes.

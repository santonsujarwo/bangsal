# Website Architecture
1. Inspect existing routes and URLs first.
2. Define hierarchy, route slugs, navigation, collections, and content relationships.
3. Preserve existing URLs for migrations unless approved.
4. Recommend fixed templates plus reusable allowlisted sections.
5. Map CMS fields to frontend fields.
6. Produce sitemap and content model docs.
7. Flag requirements needing server-side behavior beyond static Astro.

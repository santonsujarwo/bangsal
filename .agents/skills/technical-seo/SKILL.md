# Technical SEO
1. Inventory current URLs and metadata before migration.
2. Use a configured canonical site origin.
3. Implement unique titles, descriptions, canonical URLs, social metadata, and indexation controls.
4. Generate sitemap and robots directives for production and preview.
5. Add only applicable, factually supported JSON-LD.
6. Validate headings, alt text, breadcrumbs, and internal links.
7. Preserve slugs and redirects unless approved.
8. Report validation evidence; never promise rankings.

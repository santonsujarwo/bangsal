# Sveltia CMS
1. Inspect installed Sveltia CMS version and supported config before writing configuration.
2. Configure /admin/index.html and /admin/config.yml.
3. Define collections and fields that map directly to frontend schemas.
4. Configure Git backend and media paths for actual repository and host.
5. Make navigation and global settings editable when requested.
6. Document authentication; never commit secrets.
7. Test login, read, create, update, publish, and media upload.
8. Treat preview as separate and verify end-to-end.
9. Never expose arbitrary executable HTML/JS fields to editors.

# Project Kickoff Prompt

Read the root AGENTS.md and relevant skills.

First inspect the repository without modifying files. Identify:
- Framework and dependency versions
- Routes and page templates
- Content files and CMS configuration
- Navigation and global settings
- SEO metadata, redirects, sitemap, robots
- Deployment config and environment variable names
- Existing tests and scripts

Then prepare a phased plan:
1. Business and content questions
2. Sitemap and URL risks
3. Design direction
4. Astro implementation
5. Sveltia CMS integration
6. SEO and accessibility
7. QA and release criteria

Do not change files, commit, push, or deploy until the user approves the plan.

# Astro + Sveltia Starter

Minimal foundation for a Git-backed company profile website.

## Requirements
- Node.js LTS
- npm
- Git repository
- Git provider authentication configured for Sveltia CMS

## Local development
npm install
npm run dev

## Validation
npm run check
npm run build
npm run preview

CMS is available at /admin/. Update public/admin/config.yml for the real repository, branch, media paths, collections, and authentication flow. Do not assume login works until Git provider authentication has been configured and tested.
